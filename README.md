# Secure Password Generator

A simple command-line Python script to generate strong, customizable passwords.

## Description

This script is a basic tool written in Python that helps you create secure and random passwords. You can specify the desired length of the password and choose which types of characters to include: lowercase letters, uppercase letters, digits, and special symbols.

## Features

•   Generates passwords of a specified length.

•   Option to include/exclude lowercase letters (a-z).

•   Option to include/exclude uppercase letters (A-Z).

•   Option to include/exclude digits (0-9).

•   Option to include/exclude special symbols (e.g., !@#$%...).

•   Handles basic input validation (positive length, at least one character type selected).

•   Simple command-line interface.
